### 球体生成算法（地理划分法）

```
开始
  │
  ▼
┌─────────────────────┐
│ Initialize(r,lat,lon)│
└──────────┬───────────┘
           │
           ▼
┌─────────────────────┐
│   生成北极点         │
│   (0, r, 0)         │
└──────────┬───────────┘
           │
           ▼
┌─────────────────────┐
│ for lat=1 to n-1    │◄──────┐
└──────────┬───────────┘       │
           │                   │
           ▼                   │
┌─────────────────────┐       │
│ 计算纬度角 θ         │       │
└──────────┬───────────┘       │
           │                   │
           ▼                   │
┌─────────────────────┐       │
│ for lon=0 to m-1    │◄──┐   │
└──────────┬───────────┘   │   │
           │               │   │
           ▼               │   │
┌─────────────────────┐   │   │
│ 计算经度角 φ         │   │   │
└──────────┬───────────┘   │   │
           │               │   │
           ▼               │   │
┌─────────────────────┐   │   │
│ x=r·sinθ·cosφ       │   │   │
│ y=r·cosθ            │   │   │
│ z=r·sinθ·sinφ       │   │   │
└──────────┬───────────┘   │   │
           │               │   │
           ▼               │   │
┌─────────────────────┐   │   │
│ 添加到顶点表         │   │   │
└──────────┬───────────┘   │   │
           │               │   │
           └───────────────┘   │
           │                   │
           └───────────────────┘
           │
           ▼
┌─────────────────────┐
│   生成南极点         │
│   (0, -r, 0)        │
└──────────┬───────────┘
           │
           ▼
┌─────────────────────┐
│  构建三角形网格      │
│  - 北极三角扇        │
│  - 中间四边形带      │
│  - 南极三角扇        │
└──────────┬───────────┘
           │
           ▼
┌─────────────────────┐
│  计算所有面法向量    │
└──────────┬───────────┘
           │
           ▼
          结束
```

### 消隐算法（背面剔除）

```
开始渲染
  │
  ▼
┌─────────────────────┐
│ for 每个面 face     │◄────────┐
└──────────┬───────────┘         │
           │                     │
           ▼                     │
┌─────────────────────┐         │
│ 计算面中心点         │         │
└──────────┬───────────┘         │
           │                     │
           ▼                     │
┌─────────────────────┐         │
│ 应用旋转到法向量     │         │
└──────────┬───────────┘         │
           │                     │
           ▼                     │
┌─────────────────────┐         │
│ 计算视线向量         │         │
│ v = viewPoint - center│        │
└──────────┬───────────┘         │
           │                     │
           ▼                     │
┌─────────────────────┐         │
│ 计算点积             │         │
│ dot = n · v         │         │
└──────────┬───────────┘         │
           │                     │
           ▼                     │
       dot > 0?                  │
        /     \                  │
      是       否                │
      │        │                 │
      ▼        │                 │
┌──────────┐  │                 │
│ 绘制该面  │  │                 │
└─────┬────┘  │                 │
      │       │                 │
      └───────┴─────────────────┘
                │
                ▼
             渲染完成
```

### 旋转变换流程

```
RotateX/Y/Z(angle)
  │
  ▼
累加旋转角度
  │
  ▼
Transform(point)
  │
  ├─→ 绕X轴旋转
  │     │
  │     ├─→ y' = y·cos(αx) - z·sin(αx)
  │     └─→ z' = y·sin(αx) + z·cos(αx)
  │
  ├─→ 绕Y轴旋转
  │     │
  │     ├─→ x' = x·cos(αy) + z·sin(αy)
  │     └─→ z' = -x·sin(αy) + z·cos(αy)
  │
  └─→ 绕Z轴旋转
        │
        ├─→ x' = x·cos(αz) - y·sin(αz)
        └─→ y' = x·sin(αz) + y·cos(αz)
```

```

    │
    ▼
```

```
    │
    ▼
OnPaint()
    │
    ├─→ DrawCoordinateSystem()
    └─→ m_sphere.Draw()

    │
    ▼
PreTranslateMessage()
    │
    ▼
OnKeyDown()
    │
    ├─→ m_sphere.RotateX/Y/Z()
    └─→ UpdateSphere()

    │
    ├─→ OnBnClickedButtonAnimate()
    │       │
    │       ├─→ SetTimer(1, 50)
    │       └─→ KillTimer(1)
    │
    ├─→ OnBnClickedButtonSave()
    │       │
    │       └─→ m_sphere.SaveToFile()
    │
    └─→ OnBnClickedButtonLoad()
            │
            └─→ m_sphere.LoadFromFile()

    │
    ▼

    │
    ├─→ m_sphere.RotateY(0.05)
```
