# 3D球体查看器 (3D Sphere Viewer)

这是一个使用Visual Studio 2022和MFC实现的3D球体可视化应用程序。

## 功能特性

### 目标1：三维坐标系
- 在屏幕客户区中心建立三维坐标系
- X轴：水平向右（红色）
- Y轴：垂直向上（绿色）
- Z轴：垂直屏幕指向观察者（蓝色）
- 采用右手坐标系

### 目标2：球体线框模型
- 球体中心位于原点
- 使用地理划分法（经纬线网格）绘制球体
- 默认配置：20条纬线，24条经线
- 完整的三角形面片网格

### 目标3：数据文件读写
- 采用点表（顶点表）和面表构造球体数据
- 支持保存为文本文件格式（.txt）
- 支持从文件加载球体数据
- 数据文件格式清晰易读

### 目标4：消隐算法
- 实现凸多面体消隐算法
- 基于面法向量的背面剔除
- 仅显示面向观察者的表面
- 提供更清晰的3D视觉效果

### 目标5：键盘交互旋转
- ← 左箭头：绕Y轴逆时针旋转
- → 右箭头：绕Y轴顺时针旋转
- ↑ 上箭头：绕X轴逆时针旋转
- ↓ 下箭头：绕X轴顺时针旋转
- Page Up：绕Z轴旋转
- Page Down：绕Z轴反向旋转

### 目标6：动画功能
- "播放动画"按钮：启动/停止自动旋转动画
- 动画播放时球体自动绕Y轴旋转
- 帧率：20 FPS（每秒20帧）

## 编译要求

- Visual Studio 2022
- Windows SDK 10.0
- MFC支持（动态链接）
- C++17或更高版本

## 编译步骤

1. 打开Visual Studio 2022
2. 打开解决方案文件：`SphereViewer/SphereViewer.sln`
3. 选择配置（Debug或Release）和平台（x64）
4. 点击"生成" → "生成解决方案"（或按 Ctrl+Shift+B）

## 使用说明

1. 运行程序后，会看到一个对话框窗口
2. 中央显示区域显示3D球体和坐标轴
3. 使用键盘方向键交互旋转球体
4. 点击"播放动画"按钮开始/停止自动旋转
5. 点击"保存"按钮将球体数据保存到文件
6. 点击"加载"按钮从文件加载球体数据

## 核心算法说明

### 地理划分法
球体采用经纬线网格划分：
- 纬线：从北极到南极的圆环
- 经线：连接南北极的半圆
- 每个网格单元分解为两个三角形

### 坐标变换
1. 旋转变换：应用三个旋转矩阵（X、Y、Z轴）
2. 投影变换：正交投影到2D屏幕坐标

### 消隐算法
1. 计算每个面的法向量
2. 计算观察向量（从面中心到观察点）
3. 通过点积判断面是否可见
4. 仅绘制点积大于0的面（面向观察者）

## 数据文件格式

```
# Sphere 3D Model Data File
# Format: Vertex and Face tables

VERTICES <count>
x1 y1 z1
x2 y2 z2
...

FACES <count>
<num_vertices> v1 v2 v3 ...
<num_vertices> v1 v2 v3 ...
...
```

## 技术特点

- 双缓冲绘图：消除闪烁
- 预编译头：加快编译速度

- 内存管理：使用STL容器自动管理内存
- 键盘消息处理：PreTranslateMessage实现全局键盘响应
