# 应用程序界面说明

## 主界面布局

由于这是在Linux环境中创建的项目，无法实际运行和截图。但基于代码实现，以下是应用程序界面的详细描述：

### 窗口标题
```
3D球体查看器 - 使用方向键旋转球体
```

### 主显示区域
占据大部分窗口空间（466×300像素），显示内容包括：

1. **坐标轴系统**（在中心位置）
   - **X轴**：红色粗线，从中心水平向右延伸，末端标注"X"
   - **Y轴**：绿色粗线，从中心垂直向上延伸，末端标注"Y"
   - **Z轴**：蓝色粗线，从中心向左下对角线延伸，末端标注"Z"

2. **3D球体线框**
   - 蓝色细线绘制的球体网格
   - 由经纬线组成的三角形网格
   - 只显示面向观察者的表面（启用消隐后）
   - 球心位于坐标系原点

### 底部控制栏
三个按钮横向排列：

```
┌────────────┐  ┌────────────┐  ┌────────────┐
│ 播放动画    │  │   保存     │  │   加载     │
└────────────┘  └────────────┘  └────────────┘
```

- **播放动画**按钮：
  - 初始文字："播放动画"
  - 点击后变为："停止动画"
  - 再次点击恢复："播放动画"

- **保存**按钮：
  - 点击后弹出文件保存对话框
  - 默认文件名：sphere.txt
  - 文件类型：文本文件 (*.txt)

- **加载**按钮：
  - 点击后弹出文件打开对话框
  - 可以加载之前保存的球体数据

## 使用场景示例

### 场景1：初始状态
- 球体显示在中心位置
- 坐标轴清晰可见
- 球体未旋转（初始角度）
- "播放动画"按钮显示

### 场景2：手动旋转
用户按下方向键后：
1. 按 → (右箭头)
   - 球体绕Y轴顺时针旋转
   - 可以看到球体从不同角度的样子
   - 每按一次旋转约5.7度

2. 按 ↑ (上箭头)
   - 球体绕X轴向上翻转
   - 可以看到球体的顶部和底部

### 场景3：动画模式
点击"播放动画"按钮后：
1. 按钮文字变为"停止动画"
2. 球体开始自动绕Y轴连续旋转
3. 旋转速度平滑，每秒约旋转18度
4. 可以清楚地观察球体的三维结构

### 场景4：保存数据
点击"保存"按钮：
1. 弹出Windows标准文件保存对话框
2. 选择保存位置（如：桌面、文档等）
3. 输入文件名（默认：sphere.txt）
4. 点击"保存"
5. 显示成功提示消息框

### 场景5：加载数据
点击"加载"按钮：
1. 弹出Windows标准文件打开对话框
2. 浏览并选择之前保存的文件
3. 点击"打开"
4. 球体更新为文件中的数据
5. 显示成功提示消息框

## 响应性说明

### 键盘响应
- **即时响应**：按键后立即开始旋转
- **流畅动画**：双缓冲技术确保无闪烁
- **连续旋转**：长按方向键实现连续旋转

### 按钮响应
- **即时反馈**：点击按钮立即改变状态
- **视觉提示**：按钮文字变化反映当前状态
- **模态对话框**：保存/加载时显示标准文件对话框

## 与其他3D软件对比

本应用程序类似于：
- **Blender**的线框模式（但更简单）
- **3ds Max**的视口显示（但专注于单个球体）
- **MATLAB**的3D绘图（但是桌面应用而非脚本）

优势：
- 轻量级，启动快速
- 专注于教学演示
- 代码简洁易懂
- 完全独立，无需额外依赖
