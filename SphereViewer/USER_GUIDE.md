# 3D球体查看器 - 用户指南

## 一、概述

本应用程序是一个使用MFC实现的3D球体可视化工具，支持实时交互和动画演示。

## 二、界面说明

### 主界面布局
```
┌─────────────────────────────────────────┐
│  标题栏：3D球体查看器 - 使用方向键旋转球体  │
├─────────────────────────────────────────┤
│                                         │
│                                         │
│           主显示区域                     │
│        （球体和坐标系）                  │
│                                         │
│                                         │
├─────────────────────────────────────────┤
│ [播放动画] [保存] [加载]  信息栏         │
└─────────────────────────────────────────┘
```

### 坐标系说明
- **X轴**（红色）：水平向右
- **Y轴**（绿色）：垂直向上
- **Z轴**（蓝色）：垂直屏幕指向观察者
- 采用右手坐标系标准

## 三、操作说明

### 1. 键盘交互旋转

| 按键 | 功能 |
|------|------|
| ← 左箭头 | 绕Y轴逆时针旋转（向左转） |
| → 右箭头 | 绕Y轴顺时针旋转（向右转） |
| ↑ 上箭头 | 绕X轴逆时针旋转（向上转） |
| ↓ 下箭头 | 绕X轴顺时针旋转（向下转） |
| Page Up | 绕Z轴旋转 |
| Page Down | 绕Z轴反向旋转 |

**提示**：可以同时按住多个方向键实现复合旋转效果。

### 2. 动画控制

#### 播放动画
点击 **"播放动画"** 按钮：
- 球体将自动绕Y轴连续旋转
- 按钮文字变为 **"停止动画"**
- 旋转速度：约每秒18度（20帧/秒）

#### 停止动画
再次点击 **"停止动画"** 按钮：
- 球体停止自动旋转
- 按钮文字恢复为 **"播放动画"**
- 当前旋转角度保持不变

**注意**：动画播放时仍可使用键盘手动旋转球体。

### 3. 保存球体数据

点击 **"保存"** 按钮：
1. 弹出文件保存对话框
2. 选择保存位置和文件名
3. 文件扩展名建议使用 `.txt`
4. 保存成功后显示提示信息

**数据内容**：
- 所有顶点坐标（点表）
- 所有面的顶点索引（面表）
- 采用文本格式，可用记事本查看

### 4. 加载球体数据

点击 **"加载"** 按钮：
1. 弹出文件打开对话框
2. 选择之前保存的球体数据文件
3. 加载成功后球体将更新为文件中的数据
4. 显示加载成功提示信息

**支持的文件格式**：
- 程序自动保存的 `.txt` 文件
- 示例文件：`sample_sphere.txt`

## 四、技术特性

### 1. 地理划分法
球体采用经纬线网格划分方式：
- **纬线圈**：20个（从北极到南极）
- **经线**：24条（每15度一条）
- **顶点总数**：402个
- **三角形面总数**：800个

### 2. 消隐算法
采用凸多面体消隐算法（背面剔除）：
- 计算每个面的法向量
- 判断法向量是否朝向观察者
- 仅绘制面向观察者的面
- 显著提升视觉清晰度

**效果对比**：
- **开启消隐**：仅看到前半球，线条清晰
- **关闭消隐**：看到整个球体，线条重叠

当前版本默认开启消隐效果。

### 3. 双缓冲技术
- 在内存中完成所有绘图操作
- 一次性复制到屏幕
- 完全消除闪烁现象
- 提供流畅的视觉体验

## 五、数据文件格式

### 格式说明
```
# Sphere 3D Model Data File
# Format: Vertex and Face tables

VERTICES <顶点总数>
x1 y1 z1
x2 y2 z2
...

FACES <面总数>
<顶点数> v1 v2 v3 ...
<顶点数> v1 v2 v3 ...
...
```

### 示例
```
VERTICES 5
0 1 0
0.707 0.707 0
0.707 -0.707 0
-0.707 0.707 0
-0.707 -0.707 0

FACES 4
3 0 1 2
3 0 2 4
3 0 4 3
3 0 3 1
```

### 说明
- 以 `#` 开头的行为注释
- `VERTICES` 后跟顶点数量
- 每个顶点占一行，包含 x、y、z 三个坐标
- `FACES` 后跟面的数量
- 每个面第一个数字是该面的顶点数，后面是顶点索引

## 六、常见问题

### Q1: 为什么看不到完整的球体？
**A**: 这是正常现象。程序默认开启了消隐算法，只显示面向观察者的表面（前半球）。这样可以避免线条重叠，提供更清晰的视图。

### Q2: 球体旋转后如何复位？
**A**: 当前版本没有提供复位按钮。可以重新启动程序，或者通过键盘反向旋转到原始位置。

### Q3: 可以修改球体的分辨率吗？
**A**: 当前版本的分辨率（20×24）是硬编码的。如需修改，需要在源代码中修改 `Initialize` 函数的参数并重新编译。

### Q4: 支持其他3D模型吗？
**A**: 当前版本专门针对球体设计。理论上可以加载任何符合数据格式的三角形网格模型，但显示效果可能不理想。

### Q5: 动画速度可以调整吗？
**A**: 当前动画速度固定为20 FPS。如需调整，需要在源代码中修改 `SetTimer` 函数的参数（第二个参数，单位为毫秒）。
